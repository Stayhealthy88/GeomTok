# Validation Corpus — Attribution

`corpus/icons/` is a heterogeneous real-world monochrome-path icon corpus
(2,726 icons) assembled for GeomTok round-trip validation (PRD §10 gate).
Icons are sampled from the following open-source sets, used under their
respective permissive licenses:

| Set | Prefix | License |
|---|---|---|
| Tabler Icons | `tabler__`, `tablerfilled__` | MIT |
| Feather Icons | `feather__` | MIT |
| Heroicons | `heroicons__` | MIT |
| Lucide | `lucide__` | ISC |

All sets are MIT/ISC licensed and permit redistribution with attribution.
GeomTok itself is Apache-2.0; bundling these icons for test/validation purposes
is compatible with both licenses. No icon artwork is claimed as original to
GeomTok. See each upstream project for full license text.
